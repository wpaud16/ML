# JM 경매 낙찰가 예측기

아침 브리핑(JM's Schedule)의 경매 알림에서 쓰는 낙찰가 예측 모델입니다.

- `auction_predictor.py predict --danji <리치고 단지ID> --auction <리치고 경매ID>`
  → 엑스트라트리·앙상블(부스팅+군집별 회귀) 모델의 **낙찰확률 50% 가격** (JSON)
- `auction_train.csv`: 2023-06~2026-10 서울·경기 아파트 매각 1,412건 (권리위험·지분 제외), 경매 당시 시세·금리·토허·대출규제 변수
- `auction_config.json`: 최근 12개월 롤링 오차로 맞춘 50% 보정값
- 검증: 2025-02~2026-10 월별 롤링 예측, 1회 유찰 평균 오차 약 5.6~5.7%
- 2026-10-30 구축. 학습 데이터 갱신은 수동.
