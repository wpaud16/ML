# JM 경매 낙찰가 예측기

아침 브리핑(JM's Schedule)의 경매 알림에서 쓰는 낙찰가 예측 모델입니다.

- `auction_predictor.py predict --danji <리치고 단지ID> --auction <리치고 경매ID>`
  → 앙상블(부스팅+군집별 회귀) 모델의 **낙찰확률 40/45/50/55/60% 입찰가**와 **500만원 단위 입찰가별 낙찰확률** (JSON)
  - `bid_by_prob_manwon` / `bid_by_prob_eok`: 확률별 입찰가
  - `prob_by_bid_5m`: 낙찰확률 약 25~75% 구간의 500만원 단위 표
- `auction_train.csv`: 2023-06~2026-10 서울·경기 아파트 매각 1,412건 (권리위험·지분 제외), 경매 당시 시세·금리·토허·대출규제 변수
- `auction_config.json`: 최근 12개월 롤링 예측오차(확률 분포)와 로지스틱 보정값 (`calibrate`로 재계산)
- 낙찰확률 = P(실제 낙찰가 < 내 입찰가). 오차 분포를 커널로 부드럽게 만든 뒤, 2025-01 이후 1회 유찰 사건의 실제 결과로 보정. 보정 오차 약 ±5%p
- 검증: 2025-02~2026-10 월별 롤링, 1회 유찰 평균 오차 약 5.6% (순수 검증 구간 240건). 같은 확률로 입찰 시 엑스트라트리보다 낙찰 시 초과지불이 약 0.6%p 적어 앙상블 단일 모델로 확정(2026-10-30)
- 학습 데이터 갱신은 수동.
- **소규모 단지 보정 (2026-10-31~)**: 300세대 미만 단지는 예측가를 3% 낮춰 `bid_by_prob_*`·`prob_by_bid_5m`에 반영. 보정 전 값은 `small_danji_adj.bid_by_prob_manwon_raw`, 세대수는 `households`, 안내 문구는 `notes` (`warnings`는 권리위험·지분 의심 전용). 근거: 2024-07~2026-10 롤링 백테스트(986건)에서 300세대 미만은 평균 −1.5% 치우침, 10% 넘게 낮게 낙찰된 비율 약 9%(대단지 4~6%); 1회 유찰 물건에서 50% 가격 입찰 시 낙찰률 59%·초과지불 7.0% → 3% 보정 시 46%·5.1%. 값은 `auction_predictor.py`의 `SMALL_HH`, `SMALL_ADJ`.

- 권리 위험 판정 (2026-11-02~): 각 물건에 `risk` = {decision, reason, keywords, summary, resale}. 리치고 키워드와 등기 기준 권리분석 요약(상세 페이지 rights)을 비교
  - hide: 지분·유치권·법정지상권·별도등기·대지권미등기·감정가<시세60%, 또는 대항력/인수권리가 키워드와 요약 모두에 있음
  - check: 키워드와 요약이 서로 다름 (예: 키워드엔 대항력 임차인, 요약엔 없음) → 브리핑 "⚠️ 확인 필요"에 예측가와 함께 표시
  - show: 위험 없음 (재매각만 있으면 resale=true)

## 입찰 인원별 예상 낙찰가 (2026-11-02)
- `auction_train.csv`에 `bidders`(응찰자 수, 리치고 경매 상세) 열 추가 — 1,412건 중 941건 기록.
- 백테스트(월별 롤링, 인원 기록 있는 743건): 인원 없는 앙상블 평균 오차 5.12% → 인원별 사후 보정 4.55% → **인원을 변수로 넣은 앙상블 4.07%**.
- `predict_dict` 결과에 `by_bidders` 추가: 1·2·3·5·8·13명일 때 **낙찰확률 40/45/50/55/60% 입찰가**(`bid_by_prob_eok`), 중앙값(`price_eok`), 예상 입찰 인원(중앙값, 25~75% 범위; 분위 부스팅).
- 인원별 확률: 인원 모델의 롤링 예측오차를 인원 그룹(1/2/3-4/5-7/8-12/13+)별로 모은 풀(최근 18개월, `auction_config.json` `bidder_resid`)에 커널 평활 → 백테스트에서 예측 50% 구간 실제 48~52% 로 보정 없이도 맞음. 재계산: `python3 auction_predictor.py calibrate_bidders`.
  인원은 당일에야 알 수 있으므로 낙찰확률표(40~60%)는 기존 인원 없는 앙상블 그대로 쓴다.
- 오피스텔은 아직 미적용(인원 기록 555건, 효과가 아파트보다 작음).
